# Administrative Master Data

`thai_administrative_areas.csv` is generated by `python scripts/download_master_data.py`
from the `geography.json` dataset published by
[`thailand-geography-data/thailand-geography-json`](https://github.com/thailand-geography-data/thailand-geography-json).

- Contents: Thai and English province, district, subdistrict names and postal codes.
- Dataset record count at generation: 7,436 subdistrict records.
- License: MIT License, Copyright (c) 2023-Present Joe Takara.
- Purpose in this project: deterministic local reference data for address parsing.

This is an open-source reference dataset, not a certified delivery-address
validation service. Refresh and validate against an authoritative source before
shipping workflows where postal correctness is legally or financially critical.
